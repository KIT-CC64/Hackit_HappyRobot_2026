# カウント用Arduino（web/GarbageCounter/）

投入口ごとのフォトインタラプタでゴミの通過を検知し、種類別のカウントをシリアルで送信するArduinoスケッチです。

## 仕様

- ボーレート：`9600`
- センサー接続ピン：2（缶）／4（ペットボトル）／7（燃えるゴミ）
- 通過検知時にシリアルで`CAN:<count>` / `PETBOTTLE:<count>` / `BURNABLE:<count>`を送信

## 動作

各投入口のフォトインタラプタがHIGH→LOWに変化した瞬間（＝物体が通過した瞬間）を検知し、対応する種類のカウントをインクリメントしてシリアル送信します。PC側では`server/sensor_bridge.py`がこれを受信し、`POST /api/feed`でFlaskへ通知します（ゴミのカウント確定はこの経路が正規ルートです。詳細は`server/README.md`参照）。

## 書き込み・確認手順

1. Arduino IDEで`GarbageCounter.ino`を書き込む
2. シリアルモニタ（ボーレート9600）でセンサーを手動で遮り、`CAN:1`のように出力されるか確認
3. 確認後は**必ずシリアルモニタを閉じる**（開いたままだとPythonからポートが使えません）
