# サーボ制御Arduino（arduino/servo_3/）

投入口3口分（ペットボトル／缶／燃えるゴミ）のフタ開閉サーボを制御するArduinoスケッチです。

## 仕様

- ボーレート：`9600`
- サーボ接続ピン：9, 10, 11（口1〜3）
- シリアルでの整数受信：
  - `1` / `2` / `3` … 対応する口のフタを開ける（開いてから約3秒後に自動で閉じる）
  - `4` … 全ての口を開けたまま停止する（リセット・デモ終了用）

## 動作

PCから口番号（1〜3）を送ると、対応するサーボが指定角度まで回転してフタが開き、約3秒後に自動で閉位置へ戻ります。PC側の呼び出しは`server/serial_control.py`の`open_lid(servo_num)`が担います。

## 書き込み・確認手順

1. Arduino IDEで`servo_3.ino`を書き込む
2. シリアルモニタ（ボーレート9600）から`1`〜`4`を送信し、対応するサーボが動くか確認
3. 確認後は**必ずシリアルモニタを閉じる**（開いたままだとPythonからポートが使えません）
